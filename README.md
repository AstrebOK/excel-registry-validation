# Проверка реестра юридических лиц в Excel

Учебный проект: автоматическая проверка реестра организаций на ошибки перед передачей данных заказчику. Задача смоделирована по работе аналитика по внедрению продукта: получить данные от клиента, найти ошибки, вернуть клиенту понятный список исправлений и подготовить чистый реестр.

> Все данные в файле **вымышленные**: названия, ИНН, ОГРН, контакты и адреса не принадлежат реальным организациям.

**Автор:** Белорусцев Матвей Дмитриевич
**Файл:** [`Проверка_реестра_юрлиц.xlsx`](Проверка_реестра_юрлиц.xlsx)

## Что делает проект

В реестре 400 организаций. Каждая запись автоматически проверяется по семи группам правил:

| Группа | Что проверяется |
|---|---|
| ИНН | пустое значение, длина, допустимые символы, контрольная цифра |
| ОГРН | пустое значение, длина, допустимые символы, контрольная цифра |
| КПП | пустое значение, формат, совпадение кода региона с ИНН |
| Дубликаты | повтор ИНН в реестре |
| Email | формат адреса |
| Телефон | формат номера |
| Обязательные поля | наименование, адрес, контактное лицо |

Если в «Реестре» исправить запись, она сама исчезает из списка ошибок и попадает в финальный реестр.

## Структура файла

| Лист | Назначение |
|---|---|
| Инструкция | описание задачи и листов |
| Сводная | ключевые показатели, ошибки по типам (с диаграммой), результаты по регионам |
| Реестр | исходные данные и формулы проверки |
| Ошибки | автоматический список проблемных записей с текстом сообщения клиенту |
| Финальный реестр | только проверенные записи, готовые к передаче |
| Справочники | коды регионов для ВПР |

## Результат на тестовых данных

- Всего организаций: **400**
- Готово к передаче: **282** (70,5%)
- Требуют исправления: **118**
- Всего найдено ошибок: **138**

Итоги по типам ошибок и по регионам сходятся с общими числами (в «Сводной» есть контрольные строки).

## Какие приёмы Excel использованы

- `ВПР` (VLOOKUP): подстановка региона по первым двум цифрам ИНН
- `СЧЁТЕСЛИ` (COUNTIF): поиск дубликатов и подсчёт итогов
- `ИНДЕКС` + `ПОИСКПОЗ` (INDEX + MATCH): автоматическое формирование листов «Ошибки» и «Финальный реестр»
- `ЕСЛИОШИБКА` (IFERROR), `ДЛСТР` (LEN), `ЛЕВСИМВ` (LEFT), `СЖПРОБЕЛЫ` (TRIM): проверки формата
- Условное форматирование: подсветка строк с ошибками
- Сводные показатели и диаграмма на листе «Сводная»
- Автоматический текст сообщения клиенту об ошибках

## Как пользоваться

1. Скачайте файл и откройте в Excel (или LibreOffice).
2. Перейдите на лист «Реестр» и измените любую запись, например сотрите ИНН.
3. Посмотрите, как изменились листы «Ошибки», «Финальный реестр» и «Сводная».
